# Dusty user guide

Dusty turns recordings into text and Word documents on your Windows computer.
It can also translate supported spoken languages into English. You choose where
the transcripts are saved; your original recordings stay unchanged.

- [Install Dusty](install.md)
- [First run](first-run.md)
- [Transcribe a folder](transcribing.md)
- [Choose a model and manage downloads](models.md)
- [Vocabulary hints](vocabulary.md)
- [Troubleshooting](troubleshooting.md)
- [Frequently asked questions](faq.md)
- [Privacy and local data](../privacy.md)

Install only a release from the official repository, after checking its hash.

Automatic transcripts can contain mistakes, especially with names, medications,
and numbers. Always review a transcript before relying on it for medical,
legal, or other important decisions.
