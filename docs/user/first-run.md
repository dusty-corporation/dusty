# First run

1. Open Dusty. Read the welcome and accuracy notice.
2. Choose a folder for your transcripts. Dusty does not silently choose Documents,
   because it may sync to OneDrive. The folder is remembered for next time.
3. Check **Saving to** below the recording list. If it says **No folder chosen
   yet**, use **Choose folder...**. A long path is shortened in the middle;
   point at it for the complete path. Closing the welcome does not choose a folder.
4. If you need a model, use **Manage models**. When none is installed, the main
   window also offers the recommended download. Confirm the GitHub download and
   wait for **Installed**.
5. Add a short recording, check your choices in **Options...**, and press **Start**.

Start explains just above the button when a folder, model or recording is missing.
You can also choose the destination from File > Choose where to save transcripts.

The first graphics check may take longer while your driver prepares itself.
Keep the computer awake and wait for the checks to finish. Automatic uses graphics when they
work and can fall back to the processor if necessary.

If Dusty finds unfinished recordings at launch, **Resume** starts them again
immediately. A recording interrupted during processing starts from its beginning.
**Start over** discards that saved list, not the original recordings or finished
transcripts. If a welcome is still needed, it appears before the resume question.
