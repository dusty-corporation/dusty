# 0011 - Voice activity detection
- Status: Accepted
- Date: 2026-10-21
## Context
Silence can cause hallucinated transcript text.
## Decision
Use Silero VAD, converted from its MIT-licensed upstream source in CI and published with the models.
## Consequences
M1 must verify conversion and provenance.
## Alternatives considered
No VAD; worse behavior on silence.

## M7 amendment, accepted by the maintainer and PM, 2026-10-24

ISSUE-033 shows quiet or distant speech can be removed. Default VAD off for
new settings. Preserve an explicitly saved on or off choice. Offer Skip long
silences with the warning that it may miss quiet or distant speech. Continue
automatically downloading the same approved Silero model. This supersedes the
SPEC default-on rule, not the VAD implementation or license decision.


## M7 audit migration (F-08, PM approved 2026-10-25)

Pre-M7 builds persisted the old default on every save, so the old vad boolean
cannot prove an explicit choice. An unmarked legacy setting is reset off once.
New saves include vad_user_set=true; explicit choices after that migration are
preserved. Voice detection remains automatically included in model downloads.
