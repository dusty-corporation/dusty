# 0013 — Platform
- Status: Accepted
- Date: 2026-10-21
## Context
The primary user has a Windows 11 x64 laptop.
## Decision
Target Windows 11 x64 first and support Windows 10 22H2 x64; keep core code portable.
## Consequences
Windows behavior requires machine verification.
## Alternatives considered
Cross-platform release in V1; beyond the current scope.
