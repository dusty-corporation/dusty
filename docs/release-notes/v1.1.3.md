Dusty 1.1.3 adds Dusty for Mac. Private transcription that never leaves your computer, now on Windows and on Macs with Apple silicon.

## Downloads

| | File | Works on |
| --- | --- | --- |
| Windows | `Dusty-1.1.3-Setup.exe` | Windows 10 22H2 or Windows 11, 64-bit Intel or AMD |
| Mac | `Dusty-1.1.3-macos-arm64.dmg` | A Mac with Apple silicon (M1 or later), macOS 13.3 or later |

Check your download against `SHA256SUMS.txt` before opening it. Every character must match.

## Opening Dusty the first time

The downloads are free and not signed with a paid certificate, so your computer shows a one-time warning.

- **Windows:** if you see "Windows protected your PC", choose More info, then Run anyway. Setup does not need administrator rights.
- **Mac:** drag Dusty to Applications and open it. When macOS says Dusty was not opened, choose Done. Then open System Settings, Privacy & Security, and choose Open Anyway next to the Dusty message.

Never turn off your computer's security to install Dusty.

## What's new

- **Dusty for Mac.** The same features, models and privacy promises as on Windows. It uses the Mac's GPU (Metal) and falls back to the processor. Inside a virtual Mac it uses the processor.
- **Fixed:** Setup's model test and the GPU check no longer stall on computers with fewer than four processor cores.
- **Fixed:** an English-only model refuses another spoken language before any work starts.
- **Fixed:** a recording removed or made unreadable while Dusty reads it fails with a plain message.
- **Fixed:** a GPU check made before any model is installed is no longer remembered as a GPU failure.

Models download only with your permission, during Setup on Windows or in Model Manager. Your recordings and transcripts are never uploaded.
